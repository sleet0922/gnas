## 1. 产品概述

GNAS 是一个轻量级 NAS 管理面板，核心功能为 DDNS 动态域名解析管理。目标用户为家庭/小型办公 NAS 用户，提供简洁的 Web 界面管理 DNS 解析配置、查看运行日志。

- 解决家庭 NAS 动态 IP 场景下的域名自动更新需求
- 以极简的 Google 风格界面降低配置门槛

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 管理员 | 首次访问设置 | 全部操作权限 |

### 2.2 功能模块

1. **登录页**: 用户认证、首次设置
2. **概览页**: 系统状态总览、快捷入口
3. **DDNS 配置页**: DNS 服务商配置、账号设置、Webhook 通知
4. **日志页**: 运行日志查看与清除

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 登录页 | 认证表单 | 用户名/密码登录，首次访问时设置账号 |
| 概览页 | 状态卡片 | DDNS 运行状态、版本信息 |
| 概览页 | 快捷入口 | 跳转到 DDNS 配置、日志页面 |
| DDNS 配置页 | 账号设置 | 修改用户名/密码、公网访问控制 |
| DDNS 配置页 | DNS 配置 | 多配置管理，支持 6 种 DNS 服务商 |
| DDNS 配置页 | Webhook | 通知 URL/Body/Headers 配置与测试 |
| 日志页 | 日志列表 | 实时日志查看，按类型着色 |
| 日志页 | 日志操作 | 清除日志 |

## 3. 核心流程

用户首次访问 → 设置账号密码 → 登录 → 概览页查看状态 → 配置 DDNS → 查看日志

```mermaid
flowchart TD
    "访问系统" --> "是否已设置账号?"
    "是否已设置账号?" -->|"否"| "首次设置账号密码"
    "是否已设置账号?" -->|"是"| "登录页"
    "首次设置账号密码" --> "概览页"
    "登录页" --> "认证成功?"
    "认证成功?" -->|"是"| "概览页"
    "认证成功?" -->|"否"| "登录页"
    "概览页" --> "DDNS 配置页"
    "概览页" --> "日志页"
    "DDNS 配置页" --> "保存配置"
    "日志页" --> "清除日志"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色：Google Blue (#1a73e8)，辅色：#5f6368
- 按钮风格：圆角填充按钮（Google 风格），outlined 次要按钮
- 字体：Google Sans / Product Sans 风格，中文使用 Noto Sans SC
- 布局：左侧导航栏 + 右侧内容区，Google Material Design 3 风格
- 图标：Material Design Icons

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 登录页 | 认证表单 | 居中卡片，Google Logo，v-text-field，v-btn |
| 概览页 | 状态卡片 | v-card 网格布局，状态指示器，快捷链接 |
| DDNS 配置页 | DNS 配置 | v-tabs 切换配置，v-select 服务商，v-switch 启用 |
| DDNS 配置页 | Webhook | v-textarea，测试按钮 |
| 日志页 | 日志列表 | 深色终端风格 v-card，v-btn 清除 |

### 4.3 响应式

- 桌面优先，移动端自适应
- 移动端导航栏切换为底部导航
- 表单在窄屏下变为单列
